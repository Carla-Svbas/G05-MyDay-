# G05 · MyDay

O diário do percurso de estudante: app mobile feita em **Flutter/Dart** com a arquitetura **MVC**, a partir dos ecrãs desenhados no Figma.

## Estrutura da entrega

| Pasta | Conteúdo |
|---|---|
| `G05_MyDay/00_Identificacao` | Identificação do grupo |
| `G05_MyDay/01_Memoria_Descritiva` | Memória descritiva |
| `G05_MyDay/02_Imagens` | Ecrãs do Figma (`figma_XX`) e da app (`app_XX`) |
| `G05_MyDay/03_Videos` | Vídeos de demonstração e apresentação |
| `G05_MyDay/04_Documentacao_Tecnica` | Arquitetura MVC, navegação, guia de estilo, como executar |
| `G05_MyDay/05_Artefactos/my_day` | **Projeto Flutter** |
| `G05_MyDay/06_Dados_Investigacao` | Dados de investigação |
| `G05_MyDay/07_Autorizacoes` | Licenças e créditos |

## Executar a app

```
cd G05_MyDay/05_Artefactos/my_day
flutter pub get
flutter run
```

No Windows, clonem o repositório para uma pasta com caminho curto (ex.: `C:\projetos`).

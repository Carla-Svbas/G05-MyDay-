# MyDay (G05)

O diário do percurso de estudante, feito em Flutter com a arquitetura MVC.

- `lib/models/` — dados (Model)
- `lib/data/` — dados fictícios
- `lib/controllers/` — estado e operações (Controller)
- `lib/screens/` — ecrãs (View)
- `lib/widgets/` — componentes reutilizáveis

Executar: `flutter pub get` e depois `flutter run`. Testes: `flutter test`.

Documentação completa: `../../04_Documentacao_Tecnica/`.

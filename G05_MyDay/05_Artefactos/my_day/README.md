# MyDay (G05)

O diário do percurso de estudante, feito em Flutter com a arquitetura MVC.

- `lib/models/` — dados (Model)
- `lib/views/` — ecrãs (View)
- `lib/controllers/` — regras e estado (Controller)

Executar: `flutter pub get` e depois `flutter run`. Testes: `flutter test`.

Documentação completa (arquitetura, navegação, guia de estilo, contas de teste):
`../../04_Documentacao_Tecnica/`.
